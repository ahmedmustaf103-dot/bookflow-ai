# Demo video script (3–5 minutes)

**Target length:** 3:30–4:30  
**Record:** Loom or Screen Studio · 1440p · mic close  
**Show:** https://bookflow-ai-isga.vercel.app

## Cold open (0:00–0:20)

> “BookFlow AI is a multi-tenant booking OS for barbers, salons, and other appointment businesses — public booking, ops dashboard, automation, and AI on one Postgres-backed stack.”

Show landing hero → cut to booking page URL.

## Act 1 — Customer books in under a minute (0:20–1:20)

Path: `/book/bookflow`

1. Pick a service  
2. Pick staff  
3. Pick a time (show real slots)  
4. Enter details → confirm  

Narrate:

> “No app download. Branded flow. Availability comes from real staff hours and existing bookings — not a fake calendar.”

Show confirmation screen.

## Act 2 — Owner ops (1:20–2:40)

Sign in → `/dashboard`

Hit in order (15–20s each):

1. **Overview** — today’s picture  
2. **Calendar / Appointments** — new booking appears  
3. **Clients** — CRM record created  
4. **Hours / Staff / Services** — how availability is configured  
5. **Analytics** — revenue / staff / customer insight charts  

Narrate:

> “Same data model the public page used — now the shop can run the day without jumping between tools.”

## Act 3 — Automation + AI (2:40–3:50)

1. **Settings** — reminder / follow-up / review / rebooking toggles  
2. Mention outbox: confirmation email already queued/sent (show Resend or outbox if visible)  
3. **AI workbench** — generate a client summary or message draft; mention token metering / plans  

Narrate:

> “Automation isn’t a Zapier duct-tape — it’s an outbox with retries. AI is metered against the Stripe plan so margins stay sane.”

## Close (3:50–4:30)

Quick montage: white-label colour/logo if set · architecture one-liner · CTA

> “Built with Next.js, Prisma, Clerk, Stripe, and Postgres RLS. Live demo in the description — happy to walk your shop or your client’s vertical through a pilot.”

End card:

- Live: bookflow-ai-isga.vercel.app  
- Repo / portfolio link  
- Your name + calendar link
